# Synthetic Data Disclaimer

All dataset files contained within `data/synthetic/` (including `measurements.csv`, `limits.csv`, `golden_reference.csv`, `station_history.csv`, and `truth.json`) are **100% synthetically generated** for demonstration, testing, and benchmarking of the TestTrace Guard system.

- **No Proprietary Data:** These files contain no confidential, proprietary, or sensitive data from Keysight Technologies, Rohde & Schwarz, or any other commercial entity.
- **Statistical Generation:** Values are generated via parametric statistical models simulating RF S-parameter insertion loss, return loss, local oscillator leakage, phase noise, and harmonic distortion across dual automated test stations (ST-A and ST-B).
